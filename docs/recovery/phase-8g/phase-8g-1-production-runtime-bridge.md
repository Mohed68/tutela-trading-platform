# Phase 8G.1 — Production Application Runtime Bridge

Organization registration and creator-owner Membership are atomic. The
one-primary-Organization restriction is a launch policy enforced in the
application transaction, not a permanent Domain or database uniqueness rule.

Platform-submitted Organization and Offer evidence is immutable. Organization
Verification runs through the existing Application Service; committed state is
loaded and reconstructed by Replay, and only replay-derived Trust feeds
Participation. Activity Eligibility remains an independent authority composed
before Participation is relied upon. Documentary Offer evidence is bound to the
exact Verification Attempt. Controllers construct none of these authorities,
and legacy KYB or verification flags cannot bypass them.
