# Contract Document Presentation V1.1

The contract uses restrained TUTELA branding, a commercial cover treatment, clear party presentation, Part A, General Conditions 1-34, Annexes A-D, signatures, consistent headers/footers and page numbering.

Draft artifacts display `DRAFT FOR REVIEW - NOT EXECUTED` visibly on every page. Executed artifacts contain none of the words sample, template, demo, preview or not executed. Technical references, hashes and signature fingerprints appear only in the final TUTELA Execution & Integrity Record.

Every release fixture must be rendered to images and inspected for clipping, overlap, broken characters, whitespace, page transitions, signatures, headers and footers. Successful byte generation alone is not acceptance.
