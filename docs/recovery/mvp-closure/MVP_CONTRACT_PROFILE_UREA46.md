# MVP Contract Profile — Urea 46%

Profile version: `tutela-commodity-profile/urea46/v1`.

The generic contract engine selects a profile; it contains no Urea-only rendering authority. The first profile requires explicit values and evidence references for Nitrogen, Biuret, Moisture, particle/granule-size distribution and appearance/form. It also requires grade, product description, origin, quantity/unit/tolerance, price/currency, shipment/packaging, inspection, payment, documents and legal configuration. Producer is optional unless made contractually relevant.

No specification value is invented. “Agreed” is valid only when it is an explicit term supplied by the parties and remains attributable to its source reference. Missing profile fields return `NOT_READY` with stable missing-field codes. CFR and other named-place rules require the place; price and payment currency must match; ICC arbitration requires institution, seat, language and one or three arbitrators.

Current offer policy permits Urea 46% / Urea 46% Granular declarations in `MT`, `kg` or `bag`. This does not imply unit conversion, packaging equivalence, quality, origin or conformity.

Pilot operators must attach controlled evidence references for the specification and use the inspection/document annexes. The platform records assertions, not independent truth. Protected raw-document storage, laboratory/provider verification and commodity-wide profile catalogs are deferred.
