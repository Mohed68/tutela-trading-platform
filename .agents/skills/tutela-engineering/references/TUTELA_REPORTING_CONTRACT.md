# TUTELA Standard Completion Report

Return one consolidated report.

## Required header
1. Starting HEAD
2. Final HEAD
3. Commit list
4. Branch / remote parity
5. Migration number and result, if any

## Implementation
6. Objective completed
7. Modules/files changed
8. Domain/authority changes
9. UX changes
10. Security/audit changes
11. Any bounded discretionary improvements

## Verification
12. Tests added
13. Targeted test results
14. Regression suite results
15. `npm run check`
16. `npm run build`
17. Migration rehearsal / DB impact
18. Production backup, if applicable
19. Production deployment status
20. Production smoke/data-safety results

## Boundaries
21. What remains deferred
22. Legal/counsel/product approvals still required
23. Known limitations
24. Any dependency/security warnings discovered

## Final status
Provide explicit named status for every major objective in the delta and:
- READY / NOT READY for the specifically named next phase
- READY / NOT READY for Controlled Real Production Pilot, when applicable

Do not use a generic 'success' statement in place of explicit statuses.
